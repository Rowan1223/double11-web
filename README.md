# 双十一购物狂欢节 · Web 网页设计作品

> 围绕「双十一购物节」主题设计的响应式电商节日网页，使用 **原生 HTML + CSS + JavaScript** 实现，无任何打包/编译步骤，工程源码直接可运行。

## 一、项目结构

```
双十一购物节网页/
├── index.html          # 页面骨架（语义化标签，结构清晰）
├── css/
│   └── style.css       # 主题样式（红金喜庆风 + 响应式适配）
├── js/
│   └── app.js          # 核心交互逻辑（倒计时 / 领券 / 秒杀 / 购物车 / 筛选）
├── assets/             # 资源目录（本作品视觉均由 CSS/SVG/Emoji 实现，无需外部图片）
└── README.md           # 本说明文档
```

## 二、运行方式

本作品为纯静态工程，两种方式均可访问：

### 方式 A：直接双击打开
直接用浏览器打开 `index.html` 即可（推荐 Chrome / Edge / Firefox）。

### 方式 B：本地服务器（更接近真实部署，推荐）
在项目根目录执行任意一种：

```bash
# Python 自带服务器
python -m http.server 8080

# 或 Node
npx serve .
```

然后浏览器访问：`http://localhost:8080`

## 四、设计说明

- **配色**：以天猫红（`#ff1d3c`）+ 橙黄渐变 + 金色点缀，营造节日促销氛围。
- **布局**：吸顶导航 + Hero 主视觉 + 三大内容会场 + 页脚，信息层级清晰。
- **交互**：全部交互均有轻提示（toast）反馈，操作流程简洁直观。
